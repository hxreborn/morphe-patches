Manager needs Android 8.0 or later. Turn on **Pre-release patches** for this source to get early builds.

&nbsp;
## <img src="https://raw.githubusercontent.com/hxreborn/morphe-patches/assets/aqua/icons/building.png" height="48" align="absmiddle" alt="Building"> Building

You need Java 21, the Android SDK (`ANDROID_HOME` or `sdk.dir` in `local.properties`) and a GitHub
token with `read:packages`:

```bash
./gradlew buildAndroid
```

The build writes the bundle to `patches/build/libs/`. See the
[Morphe documentation](https://github.com/MorpheApp/morphe-documentation) for setup instructions.

## <img src="https://raw.githubusercontent.com/hxreborn/morphe-patches/assets/aqua/icons/requests.png" height="48" align="absmiddle" alt="Requests"> Requests

**Want an app patched?** Upvote it in the [open requests](https://github.com/hxreborn/morphe-patches/discussions/categories/app-requests?discussions_q=is%3Aopen+category%3A%22App+Requests%22+sort%3Atop), or [submit a new request](https://github.com/hxreborn/morphe-patches/discussions/new?category=app-requests) with its Play Store link and the features you want.

I'm unlikely to take on server-enforced features, region unlocks, TV or Android Auto apps, or apps another bundle already patches. I'm not taking requests for more movie and series apps or exam prep apps for now.
